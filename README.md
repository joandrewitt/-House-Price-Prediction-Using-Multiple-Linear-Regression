# House Price Prediction Using Multiple Linear Regression

## Project Overview

This project focuses on predicting house prices using Multiple Linear Regression (MLR) in Python. The project was completed as part of the Mission Ready Data Analyst Accelerator programme.

The main objective was to explore the housing dataset, prepare the data, identify relationships between features and house prices, and build a regression model to predict house prices.

## 🔍 Analysis Performed

- Loaded and explored the housing dataset
- Checked the structure and characteristics of the data
- Prepared the data for modelling
- Analysed relationships between variables
- Selected features and the target variable
- Split the data into training and testing datasets
- Built a Multiple Linear Regression model
- Generated house price predictions
- Compared predicted and actual prices
- Evaluated model performance using RMSE

## 📈 Model Evaluation

The model performance was evaluated using Root Mean Squared Error (RMSE).

RMSE was used to understand the average difference between the actual house prices and the prices predicted by the model.

## 💡 Key Learning
